En la sociedad

¿Cómo ha cambiado la sociedad?

En la actualidad, si los adultos jóvenes comparan sus vidas con las de sus padres y abuelos, las diferencias son verdaderamente sorprendentes. El amplio acceso a la información que ofrecen las tecnologías web es impresionante. La evolución de las tecnologías web, desde la Web 1.0 hasta la Web 5.0, ha revolucionado la manera en que las personas interactúan en el entorno digital, influyendo en aspectos como la identidad, la autonomía, el empleo, el gobierno, la educación y la cultura (Siregar & Sekti, 2026). Siregar y Sekti también destacan cómo la educación y la preservación cultural se han digitalizado, y cómo estas oportunidades también plantean desafíos que hacen necesario garantizar que el futuro de las tecnologías web sea inteligente, justo, ético y humano (2026).

¿Todos se benefician por igual?

Lamentablemente, acceder a la Web no siempre es una tarea sencilla para las personas con discapacidad (Nicolau & Montague, 2019). Afortunadamente, muchas de las características de las versiones más recientes de HTML permiten mejorar la accesibilidad de determinados contenidos gracias al uso de elementos semánticos. Por ejemplo, el texto alternativo (alt) y las etiquetas <strong> pueden facilitar el acceso a la información para las personas con discapacidad visual y para quienes utilizan lectores de pantalla. Sin embargo, será interesante observar qué otras tecnologías web surgirán en los próximos años para mejorar la experiencia de todos los usuarios.


Cómo contribuye HTML a la accesibilidad de las personas con discapacidad visual
Elemento o atributo HTML Función Beneficio para la accesibilidad
alt Proporciona una descripción textual de las imágenes. Permite que los lectores de pantalla transmitan información visual.
strong Identifica contenido de especial importancia. Comunica énfasis semántico a las tecnologías de asistencia.
label Asocia una etiqueta descriptiva con un campo de formulario. Facilita la identificación de los campos mediante lectores de pantalla.
nav Identifica una sección de navegación. Facilita la localización de los menús y enlaces.
main Identifica el contenido principal de una página. Permite acceder directamente al contenido principal.
